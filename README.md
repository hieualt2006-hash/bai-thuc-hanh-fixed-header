# Bài Tập Thực Hành: Tạo Fixed Header (Navbar Cố Định)

Bài thực hành kỹ thuật cố định thanh điều hướng trên đỉnh trang web khi cuộn chuột:
- `position: fixed`: Cố định menu theo viewport của trình duyệt.
- `top: 0; left: 0; width: 100%`: Căn bám sát mép trên cùng và phủ kín chiều ngang.
- `z-index: 1000`: Đảm bảo thanh menu luôn nổi lên trên các thành phần nội dung.
- `margin-top: 55px`: Bù đắp khoảng trống do thanh navbar bị nhấc khỏi luồng hiển thị thông thường, tránh che khuất nội dung.

## 🚀 Cách mở xem
Mở trực tiếp tệp [`index.html`](index.html) bằng trình duyệt web bất kỳ (Chrome, Edge, Firefox,...) và cuộn chuột lên xuống để kiểm tra hiệu ứng.
